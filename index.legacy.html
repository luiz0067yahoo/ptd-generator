Como Obter a Chave da API Gemini

Guia passo a passo para gerar sua chave gratuita no Google AI Studio

1

Acesse o Google AI Studio

Abra o portal oficial pelo link aistudio.google.com/app/apikey e faça login com sua conta Google (Gmail).

2

Clique em "Create API Key" (Criar Chave)

No canto superior ou na lista de chaves, clique no botão azul + Create API key.

3

Atenção: Selecione "Novo Projeto" Crucial

Escolha "Create API key in new project" (Criar chave em um novo projeto). Isso ativa automaticamente a cota gratuita oficial (15 requisições/minuto) sem bloqueios de permissão ou erro 429.

4

Copie o Código da Chave

Na janela de detalhes da chave gerada, clique em Copy key (Copiar chave) ou no ícone de cópia.

5

Cole na Aplicação

Cole o código no campo "Chave Gemini" no topo da página e clique em "Aplicar Chave".
